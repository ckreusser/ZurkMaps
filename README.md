# Zurk Maps

Zurk Maps is a World of Warcraft Classic battleground addon for Warsong Gulch, Arathi Basin, and Alterac Valley.

Official releases are distributed through [CurseForge](https://www.curseforge.com/wow/addons/zurk-maps). This repository is a public source mirror of finished releases; CurseForge remains the official release channel.

Zurk Maps is distributed as standard World of Warcraft addon files. There are no external executables or installers. The Lua source used by the addon is publicly viewable in this repository and is also readable directly from every installed CurseForge release.
