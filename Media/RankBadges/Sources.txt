User-authorized deterministic Python pixel recoloring for Zurk Maps r16.
HelmetMasks.json contains the exact editable coordinates for each rank.
The rank-12 helmet silhouette separates the helmet from the rank-13/14 bars.
Its intersection with gold pixels in each source preserves rank-14 silver trim.
All pixels outside the mask and all alpha values are unchanged.
Class-specific textures contain their final colors and must render with white vertex color.
Original stock textures remain in use when class colors are disabled.
